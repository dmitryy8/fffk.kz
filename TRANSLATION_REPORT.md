## 📝 ТЕХНИЧЕСКИЕ РЕКОМЕНДАЦИИ

### 1. Структура ключей переводов

Используйте понятную иерархию:
```javascript
'page_section_element': 'Текст'
```

Примеры:
- `news_card_title_1`: "Заголовок новости 1"
- `docs_calendar_2026`: "Календарь 2026"
- `federation_russia_name`: "Российская федерация"

### 2. Работа с длинными текстами

Для документов и статей:
```html
<div class="content" data-translate="docs1_full_text">
  [Русский текст]
</div>
```

### 3. Мультиязычные документы

Для документов с разными версиями:
```html
<div class="document-versions">
  <button data-lang="ru" class="active">Русский</button>
  <button data-lang="kz">Қазақша</button>
  <button data-lang="en">English</button>
</div>
```
