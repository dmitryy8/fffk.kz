## 📝 ДЕТАЛИ ПО ТИПАМ НЕПЕРЕВЕДЕННОГО КОНТЕНТА

### Что НЕ переведено:

#### 1. **HTML-комментарии**
```html
<!-- Навигация -->
<!-- Футер -->
<!-- Блок федерации -->
```
**Можно игнорировать** — не отображаются пользователям

#### 2. **Preloader текст**
```html
<div class="preloader-text">Загрузка...</div>
```
**Требует перевода** — видят все пользователи

#### 3. **Флаги языков**
```html
<div class="language-option" data-lang="ru">🇷🇺 Русский</div>
<div class="language-option" data-lang="kz">🇰🇿 Қазақша</div>
```
**Требует перевода** — часть интерфейса

#### 4. **Казахский заголовок**
```html
<h2>ҚАЗАҚСТАНДЫҚ ФУНКЦИОНАЛДЫҚ КӨПСАЙЫС ФЕДЕРАЦИЯСЫ</h2>
```
**НЕ требует перевода** — это уже казахский язык

#### 5. **Контентные тексты**
- Заголовки новостей
- Описания событий  
- Списки победителей
- Информация о партнерах

**Требует ОБЯЗАТЕЛЬНОГО перевода** — основной контент сайта
