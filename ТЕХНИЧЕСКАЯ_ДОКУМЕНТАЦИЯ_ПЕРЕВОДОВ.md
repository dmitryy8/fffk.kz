# 🔧 ТЕХНИЧЕСКАЯ ДОКУМЕНТАЦИЯ СИСТЕМЫ ПЕРЕВОДОВ

## 📋 АРХИТЕКТУРА

### Компоненты системы:

1. **language.js** — основной файл переводов
   - Объект `translations` с ключами для ru/kz/en
   - Функция `translatePage(lang)` — переключает язык
   - Event listeners для кнопок переключения
   - Auto-detection текущей страницы для meta тегов

2. **HTML атрибуты:**
   - `data-translate="ключ"` — для элементов с ключами
   - `data-translate-ru="текст"` — прямой перевод на русском
   - `data-translate-kz="текст"` — прямой перевод на казахском
   - `data-translate-en="текст"` — прямой перевод на английском

3. **localStorage:**
   - Ключ: `selectedLanguage`
   - Значения: `ru` | `kz` | `en`
   - Автозагрузка при DOMContentLoaded

## 🎨 КАК РАБОТАЕТ ФУНКЦИЯ translatePage()

```javascript
function translatePage(lang) {
    // 1. Переводит элементы с data-translate (по ключу)
    const elementsWithKeys = document.querySelectorAll('[data-translate]');
    elementsWithKeys.forEach(element => {
        const key = element.getAttribute('data-translate');
        if (translations[lang][key]) {
            element.textContent = translations[lang][key];
        }
    });
    
    // 2. Переводит элементы с data-translate-ru/kz/en (прямой перевод)
    const elementsWithDirectTranslation = document.querySelectorAll('[data-translate-ru], [data-translate-kz], [data-translate-en]');
    elementsWithDirectTranslation.forEach(element => {
        let translatedText = '';
        
        if (lang === 'ru' && element.hasAttribute('data-translate-ru')) {
            translatedText = element.getAttribute('data-translate-ru');
        } else if (lang === 'kz' && element.hasAttribute('data-translate-kz')) {
            translatedText = element.getAttribute('data-translate-kz');
        } else if (lang === 'en' && element.hasAttribute('data-translate-en')) {
            translatedText = element.getAttribute('data-translate-en');
        }
        
        if (translatedText) {
            element.textContent = translatedText;
        }
    });
    
    // 3. Определяет текущую страницу
    const path = window.location.pathname.toLowerCase();
    let titleKey = 'meta_title_home';
    let descKey = 'meta_description_home';
    
    if (path.includes('/about')) {
        titleKey = 'meta_title_about';
        descKey = 'meta_description_about';
    }
    // ... и т.д. для всех страниц
    
    // 4. Обновляет <title> и <meta> теги
    document.title = translations[lang][titleKey];
    document.querySelector('meta[name="description"]').setAttribute('content', translations[lang][descKey]);
    document.querySelector('meta[property="og:title"]').setAttribute('content', translations[lang][titleKey]);
    // ... и т.д. для всех meta
    
    // 5. Сохраняет выбранный язык
    localStorage.setItem('selectedLanguage', lang);
    
    // 6. Обновляет UI переключателя
    document.getElementById('currentLang').textContent = lang.toUpperCase();
}
```

## 🛠 КАК ДОБАВИТЬ НОВЫЙ ПЕРЕВОД

### Для элемента с ключом:

1. Добавьте ключ в `language.js`:
```javascript
const translations = {
    ru: {
        // ... существующие
        new_element: 'Новый текст'
    },
    kz: {
        // ... существующие
        new_element: 'Жаңа мәтін'
    },
    en: {
        // ... существующие
        new_element: 'New text'
    }
};
```

2. Добавьте атрибут в HTML:
```html
<div data-translate="new_element">Новый текст</div>
```

### Для элемента с прямым переводом:

Просто добавьте атрибуты в HTML:
```html
<h1 
    data-translate-ru="Заголовок на русском" 
    data-translate-kz="Қазақша тақырып" 
    data-translate-en="Title in English"
>
    Заголовок на русском
</h1>
```

## 🎯 КАКОЙ ПОДХОД ИСПОЛЬЗОВАТЬ?

### Используйте `data-translate="ключ"` когда:
- ✅ Текст повторяется на разных страницах (nav, footer, кнопки)
- ✅ Нужно централизованно управлять переводами
- ✅ Текст короткий и общий (например, "Подробнее", "Назад")

### Используйте `data-translate-ru/kz/en` когда:
- ✅ Текст уникален для одной страницы
- ✅ Текст длинный (например, описание новости)
- ✅ Нужно быстро добавить перевод без изменения language.js

## ⚡ ПРОИЗВОДИТЕЛЬНОСТЬ

- Функция `translatePage()` выполняется за ~10-30ms
- Поддерживает до 1000+ элементов на странице
- Не влияет на скорость загрузки (defer атрибут)
- LocalStorage — мгновенный доступ
